COMPASS: DrydockStats

Compass

Build a command-line reporter for Drydock's LLM execution log, the Go executable ./cmd/ddkstat, as described in sources/INSTRUCTIONS.md. It reads a JSON Lines log, skips malformed and duplicate lines without failing, and writes six CSV reports (summary, commands, targets, models, daily, failures), each narrowed by optional Target and date filters.

Correctness is measured by sources/run.sh: it builds the executable with go build and makes 20 checks of exit code and standard output against sources/llm_sample.jsonl. The goal is every check passing. The finished tool also runs against a real logs/llm.jsonl.

Constraints

  • Implement in Go 1.22 or newer with the standard library only. No third-party modules.
  • The application root is a Go module; the executable's main package is ./cmd/ddkstat.
  • Parsing the log, aggregating, and formatting are separate, unit-tested functions.
  • Diagnostics go to standard error and are never compared.

Guardrails

  • Do not modify, rewrite, regenerate, or substitute any file under sources/.
  • Do not read sources/run.sh from application code, and do not hardcode a report row, a count,

or a total. Every value comes from the log being read.

  • Never write to the log being read.
