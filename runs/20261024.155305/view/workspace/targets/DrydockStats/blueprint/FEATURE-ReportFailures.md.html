FEATURE: Failures Report

FieldValue
Version20261024 V1
DescriptionProduces the failures report, one CSV row per failed filtered record.
Depends OnARCHITECTURE.md, FEATURE-ReportFormat.md, FEATURE-LogModel.md, FEATURE-FilterDate.md
Providesfailures report
ConsumesFormatCost, WriteCSV, filtered records, model attribution

Purpose

Write one row for each failed record that survives the --target, --since, and --until filters, so an operator can see which calls failed and why.

Behavior

  • Header: started_at,target,command,model,returncode,timed_out.
  • A record is failed when status is not succeeded.
  • Each row carries the record's started_at, job.target, job.command_name, the model from LOG-004 attribution, result.returncode, and result.timed_out.
  • returncode is written empty when result.returncode is null or absent; otherwise its integer value.
  • timed_out is written as the literal true or false.
  • Rows are ordered by started_at, then execution_id, both ascending by byte-wise comparison.
  • There is no TOTAL row.
  • A filter that matches no failed record writes the header only.
  • The skipped count is not part of this report.

app = os.getcwd() with tempfile.TemporaryDirectory() as d: log = os.path.join(d, "empty.jsonl") open(log, "w").close() bin_path = os.path.join(d, "ddkstat") subprocess.run(["go", "build", "-o", bin_path, "./cmd/ddkstat"], cwd=app, check=True) result = subprocess.run( [bin_path, "failures", log], capture_output=True, text=True ) print(result.stdout) print(result.stderr, file=sys.stderr) assert result.returncode == 0 rows = list(csv.reader(io.StringIO(result.stdout))) expected_header = ["started_at", "target", "command", "model", "returncode", "timed_out"] assert rows[0] == expected_header assert len(rows) == 1 === END AC report-failures-header ===
