FEATURE: Start Date Filter

FieldValue
Version20261024 V1
DescriptionKeep records whose start date falls within the inclusive --since and --until range.
Depends OnARCHITECTURE.md, FEATURE-FilterTarget.md
Providesdate range filter
Consumesrecord stream after target filter

Purpose

--since and --until keep records whose start date lies in an inclusive range. The start date is the first 10 characters of started_at. The CLI validates the option values before this filter runs.

Behavior

  • Start date = first min(10, len(started_at)) characters of started_at.
  • With --since D, keep records whose start date is greater than or equal to D.
  • With --until D, keep records whose start date is less than or equal to D.
  • Comparison is byte-wise on YYYY-MM-DD text, which orders the same as calendar dates.
  • Options that are not given do not constrain the range.

Programmatic Acceptance

=== AC filter-date-inclusive-range ===
Intent: Records on the since and until boundaries are kept; records outside the range are dropped.
Requires: executable=python3; scope=test

def start_date(started_at): return started_at[:10]

def keep(record, since, until): d = start_date(record["started_at"]) if since is not None and d < since: return False if until is not None and d > until: return False return True

records = [ {"started_at": "2026-10-13T23:59:59.000Z"}, {"started_at": "2026-10-14T00:00:00.000Z"}, {"started_at": "2026-10-15T12:00:00.000Z"}, {"started_at": "2026-10-16T00:00:00.000Z"}, {"started_at": "2026-10-17T00:00:00.000Z"}, ] kept = [r["started_at"] for r in records if keep(r, "2026-10-14", "2026-10-16")] assert kept == [ "2026-10-14T00:00:00.000Z", "2026-10-15T12:00:00.000Z", "2026-10-16T00:00:00.000Z", ] === END AC filter-date-inclusive-range ===
