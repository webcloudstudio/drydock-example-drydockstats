# FEATURE: Report Summary

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Produce the one-row `summary` report over the filtered normalized records, with skipped counted over the whole file. |
| Depends On  | FEATURE-FilterDate.md, FEATURE-ReportFormat.md, FEATURE-LogNumeric.md |
| Provides    | ddkstat summary |
| Consumes    | FormatMinutes, FormatCost, WriteCSV, filtered records from FEATURE-FilterDate.md |

## Questions

- None.

## Purpose

`ddkstat summary <log>` writes one CSV header row and one data row to standard output. The header is
`records,skipped,succeeded,failed,first,last,input_tokens,cached_tokens,output_tokens,cost_usd,minutes`.

`skipped` counts skipped lines in the whole file and is unaffected by `--target`, `--since`, or
`--until`. Every other column is computed over the records that pass the filters. `first` and `last`
are the earliest and latest start dates, empty when no record matches. `minutes` and `cost_usd` use
the shared formatters from FEATURE-ReportFormat.md.
