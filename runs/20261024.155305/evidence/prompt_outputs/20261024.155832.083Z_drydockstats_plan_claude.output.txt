# FEATURE: Summary Report

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Produce the one-row summary CSV report over filtered records, with a whole-file skipped count. |
| Depends On  | ARCHITECTURE.md, FEATURE-LogDecode.md, FEATURE-LogRequiredFields.md, FEATURE-LogDuplicates.md, FEATURE-LogModel.md, FEATURE-LogNumeric.md, FEATURE-FilterTarget.md, FEATURE-FilterDate.md, FEATURE-ReportFormat.md |
| Provides    | summary report |
| Consumes    | records, skipped, FormatMinutes, FormatCost, WriteCSV |

## Questions

- None.

## Purpose

Write the `summary` report: one header row followed by exactly one data row.

## Report Contract

Header:

```
records,skipped,succeeded,failed,first,last,input_tokens,cached_tokens,output_tokens,cost_usd,minutes
```

- `records`: count of filtered records.
- `skipped`: count of skipped lines in the whole file, regardless of `--target` or date filters.
- `succeeded`: filtered records whose `status` is `succeeded`.
- `failed`: filtered records whose `status` is not `succeeded`.
- `first` / `last`: earliest and latest start date (first 10 characters of `started_at`) among filtered records; empty when no record matches.
- `input_tokens`, `cached_tokens`, `output_tokens`: sums over filtered records, absent values counted as zero.
- `cost_usd`: sum over filtered records, written by `FormatCost`.
- `minutes`: sum of `elapsed_ms` over filtered records, written by `FormatMinutes`.

Output is written with `WriteCSV`. Diagnostics go to standard error only.

## Programmatic Acceptance

=== AC summary-empty-file ===
Intent: A log with no records yields one data row with zero counts and empty first and last.
Suite: scoped

import json
import os
import subprocess
import sys
import tempfile

from drydock_go import cli_runner

with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "empty.jsonl")
    open(path, "w", encoding="utf-8").close()
    code, out, err = cli_runner("summary", path)
    print(out)
    print(err, file=sys.stderr)
    assert code == 0, (code, out, err)
    import csv, io
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["records", "skipped", "succeeded", "failed", "first", "last",
                       "input_tokens", "cached_tokens", "output_tokens", "cost_usd", "minutes"]
    assert len(rows) == 2
    assert rows[1][0] == "0"
    assert rows[1][4] == ""
    assert rows[1][5] == ""
=== END AC summary-empty-file ===

# FEATURE: Commands Report

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Produce the per-command CSV report over filtered records, ordered by calls descending then command ascending, with a TOTAL row. |
| Depends On  | ARCHITECTURE.md, FEATURE-LogDecode.md, FEATURE-LogRequiredFields.md, FEATURE-LogDuplicates.md, FEATURE-LogNumeric.md, FEATURE-FilterTarget.md, FEATURE-FilterDate.md, FEATURE-ReportFormat.md |
| Provides    | commands report |
| Consumes    | records, FormatMinutes, WriteCSV |

## Questions

- None.

## Purpose

Write the `commands` report: one row per `job.command_name` over filtered records, followed by a `TOTAL` row.

## Report Contract

Header:

```
command,calls,failed,input_tokens,cached_tokens,output_tokens,minutes
```

- Rows are grouped by `job.command_name`.
- Rows are ordered by `calls` descending, then `command` ascending by byte-wise comparison (AC-011).
- `failed` counts filtered records whose `status` is not `succeeded`.
- `minutes` is written by `FormatMinutes` over summed `elapsed_ms`.
- The final row is `TOTAL` over all filtered records. With no matches it is `TOTAL,0,0,0,0,0,0.0`.

## Programmatic Acceptance

=== AC commands-ordering-and-total ===
Intent: Commands rows order by calls descending then byte-wise command ascending, and the TOTAL row sums all filtered records.
Suite: scoped

import csv
import io
import os
import sys
import tempfile

from drydock_go import cli_runner

def rec(eid, cmd, status="succeeded"):
    return ('{"schema_version":1,"execution_id":"%s","started_at":"2026-10-14T01:00:00.000Z",'
            '"status":"%s","job":{"command_name":"%s","target":"T","llm":"claude","model":"haiku"},'
            '"result":{"returncode":0,"timed_out":false,"stats":{"input_tokens":1,"cached_input_tokens":2,'
            '"output_tokens":3,"cost_usd":0.1,"elapsed_ms":1000}}}') % (eid, status, cmd)

lines = [
    rec("1", "plan"),
    rec("2", "build"),
    rec("3", "build"),
    rec("4", "analyze"),
    rec("5", "analyze"),
]

with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "log.jsonl")
    with open(path, "w", encoding="utf-8") as f:
        f.write("\n".join(lines) + "\n")
    code, out, err = cli_runner("commands", path)
    print(out)
    print(err, file=sys.stderr)
    assert code == 0, (code, out, err)
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["command", "calls", "failed", "input_tokens", "cached_tokens",
                       "output_tokens", "minutes"]
    commands = [r[0] for r in rows[1:-1]]
    assert commands == ["analyze", "build", "plan"]
    total = rows[-1]
    assert total[0] == "TOTAL"
    assert total[1] == "5"
    assert total[3] == "5"
=== END AC commands-ordering-and-total ===

## User Acceptance

- None.

## Guardrails

- The commands report must not read `sources/run.sh` or embed any expected answer.
- Ordering ties on call count are resolved by byte-wise command comparison, never locale collation.

import csv
import io
import os
import sys
import tempfile

from drydock_go import cli_runner

def rec(eid, llm, job_model, stats_model=None):
    stats = '"input_tokens":1,"cached_input_tokens":2,"output_tokens":3,"cost_usd":0.1,"elapsed_ms":1000'
    if stats_model is not None:
        stats = '"model":"%s",' % stats_model + stats
    return ('{"schema_version":1,"execution_id":"%s","started_at":"2026-10-14T01:00:00.000Z",'
            '"status":"succeeded","job":{"command_name":"build","target":"T","llm":"%s","model":"%s"},'
            '"result":{"returncode":0,"timed_out":false,"stats":{%s}}}') % (eid, llm, job_model, stats)

lines = [
    rec("1", "codex", "gpt-x"),
    rec("2", "claude", "haiku", stats_model="claude-haiku-5-5"),
    rec("3", "claude", "haiku", stats_model="claude-haiku-5-5"),
]

with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "log.jsonl")
    with open(path, "w", encoding="utf-8") as f:
        f.write("\n".join(lines) + "\n")
    code, out, err = cli_runner("models", path)
    print(out)
    print(err, file=sys.stderr)
    assert code == 0, (code, out, err)
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["provider", "model", "calls", "failed", "input_tokens",
                       "cached_tokens", "output_tokens", "cost_usd"]
    pairs = [(r[0], r[1]) for r in rows[1:-1]]
    assert pairs == [("claude", "claude-haiku-5-5"), ("codex", "gpt-x")]
    total = rows[-1]
    assert total[0] == "TOTAL"
    assert total[1] == ""
    assert total[2] == "3"
=== END AC models-ordering-and-total ===

# FEATURE: Daily Report

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
