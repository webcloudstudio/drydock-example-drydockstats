FEATURE: Filter Target

FieldValue
Version20261026 V1
DescriptionKeep only records whose job.target equals a given name exactly.
Depends OnARCHITECTURE.md, FEATURE-LogNumbers.md, FEATURE-LogModel.md
Providesfilter.ByTarget
Consumeslogread.Record

Purpose

A pure function in internal/filter that narrows a record slice by Target. It performs no I/O and knows nothing about reports; every report receives its output through the CLI pipeline.

Interface

func ByTarget(records []logread.Record, name string) []logread.Record

Rules

  1. A record is kept when Record.Target == name exactly; comparison is case-sensitive.
  2. An empty name means no --target was given and all records are returned.
  3. No match returns an empty slice, never an error.
  4. Input order is preserved and the input slice is not modified.
