FEATURE: Filter Dates

FieldValue
Version20261026 V1
DescriptionKeep only records whose start date falls within an inclusive since/until range.
Depends OnARCHITECTURE.md, FEATURE-LogNumbers.md, FEATURE-LogModel.md
Providesfilter.ByDateRange
Consumeslogread.Record

Purpose

A pure function in internal/filter that narrows a record slice by start date. Dates are already validated YYYY-MM-DD text, so string comparison orders them correctly.

Interface

func ByDateRange(records []logread.Record, since, until string) []logread.Record

Rules

  1. A record is kept when Record.Date >= since and Record.Date <= until; both bounds are inclusive.
  2. An empty since or until is an unset bound and does not restrict.
  3. When since is later than until the result is empty; this is not an error and the exit code stays 0.
  4. Input order is preserved and the input slice is not modified.
