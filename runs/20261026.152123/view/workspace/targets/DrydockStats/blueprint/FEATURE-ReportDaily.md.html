FEATURE: Report Daily

FieldValue
Version20261026 V1
DescriptionWrites the daily CSV report with one row per start date and a TOTAL row.
Depends OnARCHITECTURE.md, FEATURE-CliExit.md, FEATURE-ValueFormat.md
Providesddkstat daily
Consumescli.Register, format.Minutes, logread.Record

Purpose

The daily report shows, for each start date, how many calls ran, how many failed, how many tokens they used, and how many minutes they took.

Behavior

  • Header: date,calls,failed,tokens,minutes.
  • The report covers the records that remain after the filters are applied.
  • One row per start date (the first 10 characters of started_at), in ascending byte order.
  • calls is the record count. failed is the count of records whose status is not succeeded.
  • tokens is input plus cached plus output tokens, summed over the group.
  • minutes is the group's summed elapsed_ms formatted by format.Minutes.
  • A final TOTAL row covers all filtered records.
  • When no record matches, the report writes the header and a TOTAL row of zeros with 0.0 minutes.
  • Aggregation (AggregateDaily) and writing (WriteDaily) are separate functions in internal/report.
  • The writer is registered with cli.Register("daily", ...).
  • Output is CSV, \n line endings, values unquoted.

=== AC report-daily-filters ===
Intent: The daily command honours --target, --since and --until, computing every row and the TOTAL over only the matching records.
Requires: executable=go; scope=test

import csv import io import json import os import tempfile from decimal import Decimal

from drydock_go import cli_runner

def rec(n, started, target, status, tin, ms): return { "schema_version": 1, "execution_id": "id-%03d" % n, "started_at": started, "status": status, "job": {"command_name": "build", "target": target, "llm": "claude", "model": "haiku"}, "result": { "returncode": 0, "timed_out": False, "stats": { "input_tokens": tin, "cached_input_tokens": 0, "output_tokens": 0, "elapsed_ms": ms, "cost_usd": 0.1, "model": "claude-haiku-5-5", }, }, }

recs = [ rec(1, "2026-10-14T01:00:00.000Z", "Alpha", "succeeded", 11, 60000), rec(2, "2026-10-15T01:00:00.000Z", "Alpha", "failed", 22, 60000), rec(3, "2026-10-15T02:00:00.000Z", "Beta", "succeeded", 33, 60000), rec(4, "2026-10-16T01:00:00.000Z", "Alpha", "succeeded", 44, 60000), ]

work = tempfile.mkdtemp() path = os.path.join(work, "log.jsonl") with open(path, "w", encoding="utf-8") as fh: for r in recs: fh.write(json.dumps(r) + "\n")

target = "Alpha" since = "2026-10-15" until = "2026-10-16" kept = [ r for r in recs if r["job"]["target"] == target and since <= r["started_at"][:10] <= until ]

code, out, err = cli_runner("daily", "--target", target, "--since", since, "--until", until, path) print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) body = rows[1:] assert [row[0] for row in body[:-1]] == sorted({r["started_at"][:10] for r in kept}) assert body[-1][0] == "TOTAL" assert int(body[-1][1]) == len(kept) assert int(body[-1][2]) == sum(1 for r in kept if r["status"] != "succeeded") assert int(body[-1][3]) == sum(r["result"]["stats"]["input_tokens"] for r in kept) tenths = (sum(r["result"]["stats"]["elapsed_ms"] for r in kept) + 3000) // 6000 assert Decimal(body[-1][4]) == Decimal(tenths) / Decimal(10) === END AC report-daily-filters ===

User Acceptance

  • None.

Guardrails

  • The report reads only values computed from the log; no row, count or total is hardcoded.
  • The report never writes to the log.
  • Text values are written without quoting or escaping.
