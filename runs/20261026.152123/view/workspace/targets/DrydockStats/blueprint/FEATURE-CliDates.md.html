FEATURE: Cli Dates

FieldValue
Version20261026 V1
DescriptionValidate --since and --until values as real YYYY-MM-DD calendar dates during argument parsing.
Depends OnARCHITECTURE.md, FEATURE-CliArgs.md
Providescli.ParseArgs date validation
Consumescli.ParseArgs

Purpose

A date option must be a real calendar date written YYYY-MM-DD. Anything else is a usage error that maps to exit code 2 in FEATURE-CliExit.md.

Rules

  1. A value is valid only when time.Parse("2006-01-02", v) succeeds and the parsed time formatted with the same

layout equals v exactly (rejecting shapes such as 2026-1-5).

  1. 2026-13-01 (bad month), 2026-02-30 (bad day), 2026-1-5 (wrong shape), and an empty value are usage errors.
  2. A valid date passes through to Options.Since or Options.Until unchanged.
  3. A missing value after --since or --until is a usage error.
  4. Validation is applied while parsing, so ParseArgs returns the usage error before any log is opened.
