FEATURE: Summary Report

FieldValue
Version20261025 V1
DescriptionWrite the one-row summary CSV and provide the shared CSV, minutes, and cost formatters.
Depends OnFEATURE-DateFilter.md
Providesddkstat summary
Consumesreport.FilterTarget, report.FilterDates, logread.Skipped

Purpose

ddkstat summary <log> answers how many records, skips, successes, failures, tokens, dollars and minutes the log holds, after the Target and date filters. This story also defines the formatting helpers every other report reuses.

Output

Header, exactly:

records,skipped,succeeded,failed,first,last,input_tokens,cached_tokens,output_tokens,cost_usd,minutes

One data row:

  • records is the count of kept, filtered records. succeeded has status succeeded; failed is every other status.
  • skipped is the count of skipped lines in the whole file, regardless of filters.
  • first and last are the earliest and latest start dates (YYYY-MM-DD) among matching records, empty when none match.
  • input_tokens, cached_tokens, output_tokens are sums of input_tokens, cached_input_tokens, output_tokens; absent values count as zero.
  • cost_usd is the summed cost_usd written with %.4f.
  • minutes is the summed elapsed_ms as tenths of a minute: t = (ms + 3000) / 6000 in integer division, written t/10, ., t%10.

Shared formatting

  • CSV has one header row and \n line endings, with no \r.
  • Aggregation and formatting are separate functions: aggregation returns numbers, formatting turns them into text.
  • Minutes rounding applies to the group's summed milliseconds, never to per-record values.
  • With no matching record: records 0, first and last empty, sums 0, cost 0.0000, minutes 0.0.

import csv, io, json, os, tempfile from drydock_go import cli_runner

def rec(i, target="T1", day="2026-10-14", status="succeeded", cmd="build", llm="claude", model="m", inp=10, cached=20, out=30, ms=60000, cost=0.25, ts=None): return {"execution_id": f"id-{i}", "started_at": ts or f"{day}T01:02:03.004Z", "status": status, "job": {"command_name": cmd, "target": target, "llm": llm, "model": model}, "result": {"returncode": 0 if status == "succeeded" else 1, "timed_out": False, "stats": {"input_tokens": inp, "cached_input_tokens": cached, "output_tokens": out, "elapsed_ms": ms, "cost_usd": cost}}}

def run(lines, *args): with tempfile.TemporaryDirectory() as d: p = os.path.join(d, "llm.jsonl") with open(p, "w", encoding="utf-8") as f: for l in lines: f.write((l if isinstance(l, str) else json.dumps(l)) + "\n") code, out, err = cli_runner(*args, p) assert code == 0 print(out) print(err) return code, out

recs = [ rec(1, day="2026-10-15", inp=1, cached=2, out=3, ms=100000, cost=0.25), rec(2, day="2026-10-14", inp=10, cached=20, out=30, ms=200000, cost=0.5, status="failed"), rec(3, day="2026-10-16", inp=100, cached=200, out=300, ms=50000, cost=1.0), ] code, out = run(recs, "summary") assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["records", "skipped", "succeeded", "failed", "first", "last", "input_tokens", "cached_tokens", "output_tokens", "cost_usd", "minutes"] assert len(rows) == 2 d = dict(zip(rows[0], rows[1])) st = lambda r: r["result"]["stats"] assert int(d["records"]) == len(recs) assert int(d["succeeded"]) == len([r for r in recs if r["status"] == "succeeded"]) assert int(d["failed"]) == len([r for r in recs if r["status"] != "succeeded"]) assert d["first"] == min(r["started_at"][:10] for r in recs) assert d["last"] == max(r["started_at"][:10] for r in recs) assert int(d["input_tokens"]) == sum(st(r)["input_tokens"] for r in recs) assert int(d["cached_tokens"]) == sum(st(r)["cached_input_tokens"] for r in recs) assert int(d["output_tokens"]) == sum(st(r)["output_tokens"] for r in recs) assert abs(float(d["cost_usd"]) - sum(st(r)["cost_usd"] for r in recs)) < 1e-9 assert len(d["cost_usd"].split(".")[1]) == 4 t = (sum(st(r)["elapsed_ms"] for r in recs) + 3000) // 6000 assert float(d["minutes"]) == t / 10 assert len(d["minutes"].split(".")[1]) == 1 === END AC summary-columns-and-sums ===

Rounding applies to the sum, not to each record.

parts = [2000, 2000, 2000] code, out = run([rec(i, ms=m) for i, m in enumerate(parts)], "summary") rows = list(csv.reader(io.StringIO(out))) cell = dict(zip(rows[0], rows[1]))["minutes"] t = (sum(parts) + 3000) // 6000 assert float(cell) == t / 10 === END AC summary-minutes-rounding ===
