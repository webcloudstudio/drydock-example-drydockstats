Purpose

ddkstat is a command-line reporter for Drydock's LLM execution log (logs/llm.jsonl). It reads a JSON Lines file, skips malformed and duplicate lines, narrows the records by optional Target and date filters, and writes one of six CSV reports to standard output. It has no database and no network access, and it never writes to the log it reads.

Shared Types and Interfaces

// internal/logread
type Record struct {
    ExecutionID  string
    StartedAt    string // RFC 3339 UTC; the first 10 characters are the start date
    Status       string
    Command      string // job.command_name
    Target       string // job.target
    Provider     string // job.llm
    Model        string // result.stats.model when non-empty, otherwise job.model
    InputTokens  int64
    CachedTokens int64
    OutputTokens int64
    CostUSD      float64
    ElapsedMS    int64
    ReturnCode   *int // nil when null or absent
    TimedOut     bool
}

func (r Record) Date() string   // StartedAt[:10]
func (r Record) Failed() bool   // Status != "succeeded"

type Result struct {
    Records []Record // kept records in file order
    Skipped int      // skipped lines in the whole file
}

func Read(r io.Reader, warn io.Writer) (Result, error)
func ReadFile(path string, warn io.Writer) (Result, error)
// internal/cli
type Options struct {
    Report string
    Target string
    HasTarget bool
    Since  string // YYYY-MM-DD or empty
    Until  string // YYYY-MM-DD or empty
    Log    string
}

func Parse(args []string) (Options, error)
func Run(args []string, stdout, stderr io.Writer) int

Run uses a local flag.FlagSet with flag.ContinueOnError or an equivalent hand parser, never the global flag set, and is tested with bytes.Buffer. Report output is buffered and written to standard output only after the log has been read successfully, so a failing command leaves standard output empty.

Execution Flow

parse arguments, open the log, ingest records applying the skip rules, apply the Target and date filters, compute one report, write CSV. The skipped count is computed over the whole file before any filter applies.

Shared Output Rules

CSV with one header row and \n line endings; minutes written as tenths with t = (ms + 3000) / 6000 in integer division and formatted t/10, ., t%10; cost written with %.4f; text ordered by byte value; a TOTAL row of zeros when no record matches, where the report has one.

Exit Codes

CodeMeaning
0Success, including skipped lines or no matching records
1The log cannot be opened or read
2Usage error

Diagnostics go to standard error and are never compared.

Persistence Ownership

BoundaryOwner module
Persistence, configuration, file stores, external servicesNone; the application has no database and no external service. The log is read-only input.

Technical Decisions

  • Records that fail any rule never register their execution_id, so a later valid record with that

id is kept.

  • --help is an unknown option and exits 2 with the usage line on standard error.
  • A repeated option keeps its last occurrence.
  • A directory given as the log path is an unreadable log and exits 1.
  • A numeric field with a JSON type other than number or null counts as zero.

Guardrails

  • Standard library only; no third-party module and no database.
  • Never modify, rewrite, or substitute any file under sources/.
  • Application code never reads sources/run.sh and never embeds a report row, count, or total.
  • Never write to the log being read.
  • Only cmd/ddkstat calls os.Exit.
