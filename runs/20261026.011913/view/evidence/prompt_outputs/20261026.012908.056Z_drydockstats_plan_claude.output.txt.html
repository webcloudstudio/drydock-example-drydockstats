# FEATURE: Commands Report

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Write one CSV row per Drydock command, ordered by calls then name, followed by a TOTAL row. |
| Depends On  | FEATURE-SummaryReport.md |
| Provides    | ddkstat commands |
| Consumes    | report.FilterTarget, report.FilterDates, shared CSV, minutes, and cost formatters |

## Questions

- None.

## Purpose

`ddkstat commands <log>` shows which Drydock commands made the most LLM calls and what they used.

## Output

Header, exactly:

```text
command,calls,failed,input_tokens,cached_tokens,output_tokens,minutes
```

- One row per distinct `job.command_name` among filtered records.
- Rows are ordered by `calls` descending, then `command` ascending by byte value.
- `failed` counts records whose status is not `succeeded`.
- Token columns are sums; `minutes` is the group's summed `elapsed_ms` formatted by the shared minutes rule.
- The final row is `TOTAL` with the same columns summed over all filtered records.
- With no matching record: the header and `TOTAL,0,0,0,0,0,0.0`.

import csv, io, json, os, tempfile
from collections import Counter
from drydock_go import cli_runner

def rec(i, target="T1", day="2026-10-14", status="succeeded", cmd="build", llm="claude", model="m", inp=10, cached=20, out=30, ms=60000, cost=0.25, ts=None):
    return {"execution_id": f"id-{i}", "started_at": ts or f"{day}T01:02:03.004Z", "status": status,
            "job": {"command_name": cmd, "target": target, "llm": llm, "model": model},
            "result": {"returncode": 0 if status == "succeeded" else 1, "timed_out": False,
                       "stats": {"input_tokens": inp, "cached_input_tokens": cached, "output_tokens": out, "elapsed_ms": ms, "cost_usd": cost}}}

def run(lines, *args):
    with tempfile.TemporaryDirectory() as d:
        p = os.path.join(d, "llm.jsonl")
        with open(p, "w", encoding="utf-8") as f:
            for l in lines:
                f.write((l if isinstance(l, str) else json.dumps(l)) + "\n")
        code, out, err = cli_runner(*args, p)
        print(out)
        print(err)
        return code, out

cmds = ["build"] * 3 + ["plan"] * 2 + ["analyze"] * 2 + ["diagnose"]
recs = [rec(i, cmd=c) for i, c in enumerate(cmds)]
code, out = run(recs, "commands")
assert code == 0
rows = list(csv.reader(io.StringIO(out)))
assert rows[0] == ["command", "calls", "failed", "input_tokens", "cached_tokens", "output_tokens", "minutes"]
counts = Counter(cmds)
expected = sorted(counts, key=lambda c: (-counts[c], c.encode()))
data = rows[1:-1]
assert [r[0] for r in data] == expected
for r in data:
    assert int(r[1]) == counts[r[0]]
assert rows[-1][0] == "TOTAL"
