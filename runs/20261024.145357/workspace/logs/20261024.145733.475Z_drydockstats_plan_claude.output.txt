# FEATURE: Log Read

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Reads the Drydock LLM execution log as UTF-8 JSON Lines and decodes each non-blank line into one record. |
| Depends On  | ARCHITECTURE.md |
| Provides    | log-read |
| Consumes    | — |

## Questions

- None.

## Purpose

The reporter answers its questions from a single JSON Lines file, `logs/llm.jsonl`, passed as the log path. This feature opens that file, reads it as UTF-8, and decodes each non-blank line as one JSON object. It is the first stage of the pipeline: every later stage (skip rules, filters, reports) receives the records this feature produces.

## Behavior

- The log path is opened and read as UTF-8, one line at a time.
- A blank line (empty, or containing only whitespace) is ignored and is not counted anywhere.
- Every other line is decoded with `encoding/json` into one value. Lines that do not decode to a JSON object are passed to the skip rules as they are; this feature does not decide whether a record is kept.
- The decoded record type holds only the fields the reporter reads: `execution_id`, `started_at`, `status`, `job.command_name`, `job.target`, `job.llm`, `job.model`, `result.returncode`, `result.timed_out`, and the optional `result.stats` numbers and model. Every other field is ignored.
- A read or open failure of the log path is an operational failure. The feature returns it to the caller so the command line can map it to exit code 1.
- The feature never writes to the log.

## Programmatic Acceptance

=== AC log-read-decodes-records ===
Intent: Every non-blank line of a valid log is decoded and the read result reports the expected count of decoded lines.
Requires: executable=python3; scope=test

import json
import os
import subprocess
import sys
import tempfile

ROOT = os.getcwd()
lines = [
    '{"execution_id":"a","started_at":"2026-10-14T01:00:00.000Z","status":"succeeded","job":{"command_name":"build","target":"T","llm":"claude","model":"haiku"}}',
    "",
    '{"execution_id":"b","started_at":"2026-10-14T02:00:00.000Z","status":"failed","job":{"command_name":"plan","target":"T","llm":"claude","model":"haiku"}}',
]
with tempfile.TemporaryDirectory() as tmp:
    path = os.path.join(tmp, "llm.jsonl")
    with open(path, "w", encoding="utf-8") as f:
        f.write("\n".join(lines) + "\n")
    result = subprocess.run(
        ["go", "run", "./cmd/ddkstat", "summary", path],
        cwd=ROOT, capture_output=True, text=True,
        env={**os.environ},
    )
    print(result.stdout)
    print(result.stderr, file=sys.stderr)
    assert result.returncode == 0
    assert result.stdout.splitlines()[1].split(",")[0] == "2"
=== END AC log-read-decodes-records ===

=== AC log-read-utf8 ===
Intent: The log is read as UTF-8, so a non-ASCII target name is decoded and reported intact.
Requires: executable=python3; scope=test

import csv
import io
import os
import subprocess
import sys
import tempfile

ROOT = os.getcwd()
target = "Café"
record = '{"execution_id":"u","started_at":"2026-10-14T01:00:00.000Z","status":"succeeded","job":{"command_name":"build","target":"' + target + '","llm":"claude","model":"haiku"}}'
with tempfile.TemporaryDirectory() as tmp:
    path = os.path.join(tmp, "llm.jsonl")
    with open(path, "w", encoding="utf-8") as f:
        f.write(record + "\n")
    result = subprocess.run(
        ["go", "run", "./cmd/ddkstat", "targets", path],
        cwd=ROOT, capture_output=True, text=True, encoding="utf-8",
        env={**os.environ},
    )
    print(result.stdout)
    print(result.stderr, file=sys.stderr)
    assert result.returncode == 0
    rows = list(csv.reader(io.StringIO(result.stdout)))
    assert rows[1][0] == target
=== END AC log-read-utf8 ===

=== AC log-read-missing-file ===
Intent: An unreadable log path is an operational failure that exits 1 and writes nothing to standard output.
Requires: executable=python3; scope=test

import os
import subprocess
import sys
import tempfile

ROOT = os.getcwd()
with tempfile.TemporaryDirectory() as tmp:
    missing = os.path.join(tmp, "absent.jsonl")
    result = subprocess.run(
        ["go", "run", "./cmd/ddkstat", "summary", missing],
        cwd=ROOT, capture_output=True, text=True,
        env={**os.environ},
    )
    print(result.stdout)
    print(result.stderr, file=sys.stderr)
    assert result.returncode == 1
    assert result.stdout == ""
