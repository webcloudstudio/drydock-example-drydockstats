## Purpose

`ddkstat` is a single-process, read-only command-line reporter. It reads one Drydock LLM execution log in JSON Lines form, skips malformed and duplicate lines without failing, applies optional Target and date filters, and writes one CSV report to standard output. The product is built in Go 1.22 or newer with the standard library only.

## Delivery Shape

Execution flow for every invocation:

1. `cmd/ddkstat` passes `os.Args[1:]` to `internal/cli`.
2. `internal/cli` parses the report name, options, and the single log path, and validates them.
3. `internal/record` opens the log, reads it as UTF-8, decodes and normalizes each line, and applies the skip rules.
4. `internal/filter` keeps the normalized records that match the supplied Target and date options.
5. `internal/report` aggregates the filtered records for the selected report.
6. `internal/format` renders minutes, cost, and CSV rows, and `internal/cli` writes the result to standard output.

Standard output carries only the CSV report. Diagnostics go to standard error. The exit code is `0`, `1`, or `2` as defined below.

## Module Layout

```
go.mod                      # module ddkstat; go 1.22; no require directives
cmd/
  ddkstat/                  # package main: process entry point only
internal/
  cli/                      # argument parsing, validation, dispatch, exit codes
  record/                   # JSON Lines reading, decoding, normalization, skip rules
  filter/                   # Target and date predicates over normalized records
  report/                   # aggregation for the six reports
  format/                   # minutes and cost formatting, CSV writing
bin/
  test.sh                   # POSIX launcher: go vet ./... and go test ./...
```

The module path is `ddkstat`. It is not declared in any source; this is a plan-level choice recorded in `DECISIONS.json`. Application packages live under `internal/` and are not importable outside the module.

## Package Boundaries

| Package | Owns | Exposes | Must not |
|---|---|---|---|
| `cmd/ddkstat` | Process startup | `main` | Contain logic; it is the only caller of `os.Exit`. |
| `internal/cli` | Arguments, option validation, report dispatch, stream and exit-code mapping | `Run(args []string, stdout, stderr io.Writer) int` | Parse log lines or compute aggregates. |
| `internal/record` | Reading the file, decoding, required-field checks, duplicate tracking, model resolution, numeric defaults | `Read(r io.Reader) (Result, error)`, `Record`, `Result` | Know about filters or reports. |
| `internal/filter` | Predicates for Target, `--since`, `--until`, and the combined filter | `Apply(records []record.Record, f Options) []record.Record` | Read files or format output. |
| `internal/report` | Grouping, ordering, sums, and TOTAL rows for each report | One function per report, each returning typed rows | Format numbers as text. |
| `internal/format` | `t = (ms + 3000) / 6000` minutes text, `%.4f` cost text, CSV writing | `Minutes(ms int64) string`, `Cost(v float64) string`, `WriteCSV(w io.Writer, header []string, rows [][]string) error` | Decide which records are included. |

Parsing, aggregating, and formatting are separate functions, and each is unit-tested in its own package.

## Module Ownership

| Boundary | Owner | Access allowed |
|---|---|---|
| Log file | `internal/record` | Read-only open and read. Never write. |
| Standard output | `internal/cli` | Writes the CSV report only after it is computed without error. |
| Standard error | `internal/cli` and `internal/record` | Warnings for skipped lines and one diagnostic line on failure. |
| Process exit | `cmd/ddkstat` | `os.Exit` only. |

## Record Model

`record.Record` holds only the fields the reporter reads:

| Field | Source | Notes |
|---|---|---|
| `ExecutionID` | `execution_id` | Identity, required non-empty string. |
| `StartedAt` | `started_at` | Required non-empty string. |
| `StartDate` | first 10 characters of `started_at` | Used by filters and the daily report. |
| `Status` | `status` | Required non-empty string. |
| `Failed` | derived | True when `Status` is not `succeeded`. |
| `Command` | `job.command_name` | Required non-empty string. |
| `Target` | `job.target` | Required non-empty string. |
| `Provider` | `job.llm` | Used by the models report. |
| `Model` | `result.stats.model`, else `job.model` | Non-empty `result.stats.model` wins. |
| `InputTokens`, `CachedTokens`, `OutputTokens` | `result.stats` | Absent or null means zero. |
| `CostUSD` | `result.stats.cost_usd` | Absent or null means zero. |
| `ElapsedMS` | `result.stats.elapsed_ms` | Absent or null means zero. |
| `ReturnCode` | `result.returncode` | Pointer; nil when null or absent. |
| `TimedOut` | `result.timed_out` | Boolean. |

A line without a `result.stats` object is still a record. Its numeric fields are zero.

## Interfaces

- `cli.Run(args []string, stdout, stderr io.Writer) int` is the only entry used by `cmd/ddkstat`. It uses a local `flag.FlagSet` with `flag.ContinueOnError` and is tested with `bytes.Buffer` writers.
- `record.Read` returns the kept records and the whole-file skipped count. Skipped lines produce one stderr warning each, naming the line number.
- `filter.Apply` is a pure function. The skipped count bypasses filters.
- Each report function in `internal/report` returns typed rows; `internal/format` turns them into text.

## Exit and Stream Contract

| Code | Condition | stdout | stderr |
|---|---|---|---|
| `0` | Success, including skipped lines or zero matches | CSV report | Skip warnings only |
| `1` | Log cannot be opened or read as a file | Nothing | One diagnostic line |
| `2` | Usage error: unknown report or option, missing option value, invalid date, zero or extra log path | Nothing | One diagnostic line |

## Technical Decisions

- The module is named `ddkstat`. The record package is named `record`, not `log`, to avoid colliding with the standard `log` package.
- Option values are read by `flag` with `ContinueOnError`; an unknown flag or missing value is a usage error.
- The reporter reads the whole file once and keeps the normalized records in memory; it never streams output before the report is computed.
- Tests write their own logs under `t.TempDir()` and never read `sources/run.sh` or any Blueprint document.

## User Acceptance

- None.

## Guardrails

- Never read `sources/run.sh` from application code, and never embed a report answer or a count.
- Never write to the log being read.
- Never add a third-party module; the standard library is the only dependency source.
- `cmd/ddkstat` is the only caller of `os.Exit`.
- Standard error is diagnostic only and is never the acceptance oracle.
