Version20261024 V1
DescriptionAssemble the end-to-end ddkstat run from arguments to one written report.

Providesddkstat <report> [options] <log> end-to-end
Consumesargument parser, reader, parser, filters, six reports, usage and read-failure paths

Purpose

Assembly feature. A single run parses arguments, reads the log, skips invalid lines, applies the active filters, aggregates, and writes exactly one selected report to standard output. Diagnostics go to standard error. Exit codes follow the contract in sources/INSTRUCTIONS.md: 0 for success, 1 for an unreadable log, 2 for a usage error.

Programmatic Acceptance

=== AC pipeline-each-report-exits-zero ===
Intent: Every one of the six reports runs end to end over the sample and exits 0 with non-empty stdout.
Suite: scoped
Requires: executable=python3; scope=test

from drydock_go import cli_runner

sample = os.path.join("sources", "llm_sample.jsonl") for report in ["summary", "commands", "targets", "models", "daily", "failures"]: code, out, err = cli_runner(report, sample) print(report, code, err) assert code == 0, (report, code, out, err) assert out.strip() != "", report === END AC pipeline-each-report-exits-zero ===
