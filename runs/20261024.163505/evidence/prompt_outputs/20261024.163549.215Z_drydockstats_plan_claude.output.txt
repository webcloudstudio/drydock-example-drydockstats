## story log-skip
summary:      Parse records and skip non-object, incomplete, and duplicate lines.
type:         service
kind:         capability
phase:        1
implements:   FEATURE-LogSkip.md
covers:       LOG-002
accepts:      st-004
stack:        go.md
provides:     record parser with whole-file skipped count
consumes:     line reader
depends:      log-read
acceptance:   yes
instructions: |
  Parse each line as a JSON object. Skip a line that is not an object, lacks a non-empty execution_id, started_at, status, job.command_name, or job.target, or repeats the execution_id of an earlier kept record. Keep the first occurrence. Write one stderr warning per skipped line naming its line number, and never write to stdout. Skipping never changes the exit code. Expose the total skipped count over the whole file.
